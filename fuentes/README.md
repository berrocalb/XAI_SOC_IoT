# Fuentes del artículo

Esta carpeta contiene los PDF de las referencias citadas en el artículo, nombrados con su código (`R01` a `R25`).

- `manifest_fuentes.csv`: código, cita, nombre de archivo, URL de descarga, DOI y tipo de acceso.
- `descargar_fuentes.py`: descarga automática de las fuentes de acceso abierto (`python fuentes/descargar_fuentes.py`).
- `pendientes_descarga_manual.csv`: se genera al ejecutar el script; lista las fuentes de suscripción o las que el
  sitio no permitió descargar. Descárguelas manualmente y guárdelas con el nombre indicado.

La relación entre cada parte del artículo y su archivo está en `../docs/trazabilidad.md` y en la hoja
"Paper-Fuentes" de `Matriz_trazabilidad_paper.xlsx`.
